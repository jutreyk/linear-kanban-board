# linear-kanban-board

Канбан-доска для управления задачами в темной теме в стиле Linear. Написана на React 19, TypeScript, Tailwind CSS, Zustand и `@dnd-kit`.

## Функционал

- Перетаскивание карточек между колонками через `@dnd-kit`.
- Быстрое создание тикета по клавише `C`.
- Палитра команд по `Ctrl+K` (или `Cmd+K`): поиск, переключение колонок, фильтрация.
- Фильтры по приоритетам и меткам, текстовый поиск по названию или ID задачи.
- Оценка задач в сторипоинтах (шкала Фибоначчи) и подсчет суммарных очков в колонках.
- Чеклисты подзадач внутри карточки и дедлайны с подсветкой просроченных.
- Экспорт спринта в JSON и CSV.
- Сохранение состояния в `localStorage`.

## Горячие клавиши

| Сочетание | Действие |
|---|---|
| `C` | Создать задачу |
| `Ctrl+K` / `Cmd+K` | Открыть палитру команд |
| `Esc` | Закрыть модальное окно |

## Запуск

```bash
npm install
npm run dev
```

Приложение запустится на `http://localhost:5173/`.

Сборка продакшен-бандла:

```bash
npm run build
```
