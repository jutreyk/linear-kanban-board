# linear-kanban-board

Канбан-доска для отслеживания задач в интерфейсном стиле Linear на React 19, TypeScript, Tailwind CSS, Zustand и `@dnd-kit`.

Визуальный язык и цветовые токены вдохновлены дизайн-системой **Linear.app** (из открытого репозитория спецификаций [awesome-design-md](https://github.com/VoltAgent/awesome-design-md)): глубокий тёмный холст `#08090a`, угольные карточки `#0f1011`, тонкие разделители `#222326` и лавандовый акцент `#5e6ad2`.

## Возможности
- Перетаскивание карточек между колонками через `@dnd-kit/core`.
- Локальное управление состоянием через Zustand.
- Автоматическое сохранение состояния доски и задач в `localStorage`.
- Быстрое создание задач с указанием приоритета.
- Живой поиск и фильтрация по названию или идентификатору.

## Запуск

```bash
npm install
npm run dev
```

Локальный сервер запустится по адресу `http://127.0.0.1:5173/`.
