# linear-kanban-board

Канбан-доска для управления инженерными спринтами и задачами в эстетике **Linear.app**. Построена на стеке React 19, TypeScript, Tailwind CSS, Zustand и `@dnd-kit`.

Визуальный язык и дизайн-токены соответствуют спецификации тёмной темы Linear: глубокий холст `#08090a`, угольные карточки `#0f1011`, микро-бордеры `#222326` и фирменный акцент `#5e6ad2`.

---

## Ключевые возможности

- **Drag-and-Drop с физикой**: плавное перетаскивание карточек на базе `@dnd-kit` с пружинной анимацией сброса (`cubic-bezier`), наклоном при захвате и мягкой подсветкой активной колонки.
- **Два режима отображения**: мгновенное переключение между классической **Канбан-доской** и компактным **Табличным списком (List View)**.
- **Keyboard-First UX**:
  - `C` — быстрое открытие модалки создания нового тикета.
  - `Ctrl + K` / `Cmd + K` — палитра команд (быстрый переход, смена вида, фильтры, экспорт и живой поиск задач).
  - `Esc` — закрытие активных модальных окон.
- **Детализация и инлайн-редактирование**: по клику на задачу открывается окно редактирования названия, статуса, приоритета, дедлайнов и меток.
- **Чеклисты подзадач**: добавление сабтасков к тикету с прогресс-индикатором выполнения на карточке (`2/3`).
- **Сроки сдачи (Due Dates)**: выбор даты выполнения задачи и подсветка просроченных тикетов (*Overdue warning*).
- **Оценка сложности и аналитика спринта**:
  - Шкала сторипоинтов Фибоначчи (`1, 2, 3, 5, 8 pt`).
  - Подсчёт суммарной ёмкости в заголовке каждой колонки.
  - **Sprint Analytics Bar**: сводка прогресса спринта (`% Done`), соотношение выполненных очков и мультисегментная полоса готовности.
- **Фильтрация и поиск**: быстрые фильтры по приоритетам (*Срочные, Высокие, Средние, Низкие*), выпадающий список меток и живой поиск по названию или коду тикета.
- **Экспорт данных**: выгрузка текущего спринта в форматы **JSON** и **CSV**.
- **Персистентность**: сохранение состояния доски и задач в `localStorage` с версионированием схемы данных.

## Горячие клавиши

| Комбинация | Действие |
|---|---|
| `C` | Открыть модальное окно создания задачи |
| `Ctrl + K` / `Cmd + K` | Открыть палитру команд (Command Palette) |
| `Esc` | Закрыть текущее модальное окно |

## Архитектура проекта

Кодовая база декомпозирована по доменным областям ответственности:

```text
src/
├── types/
│   └── kanban.ts              # Типы данных (Task, Column, Subtask, SprintStats)
├── store/
│   └── useKanbanStore.ts      # Стейт-менеджер Zustand и работа с localStorage
└── components/
    ├── board/
    │   ├── KanbanColumn.tsx   # Дроп-зона колонки и суммарные поинты
    │   └── TaskCard.tsx       # Сортируемая карточка задачи с dnd-хуками
    ├── list/
    │   └── TaskListView.tsx   # Табличное представление спринта
    ├── analytics/
    │   └── SprintAnalyticsBar.tsx # Прогресс-бар и метрики спринта
    └── modals/
        ├── CommandPalette.tsx # Палитра команд (Ctrl+K)
        ├── QuickCreateModal.tsx # Быстрое создание задачи
        └── TaskDetailModal.tsx  # Детализация, чеклист и дедлайны
```

## Запуск проекта

```bash
npm install
npm run dev
```

Локальный сервер разработки запустится по адресу `http://localhost:5173/`.

Сборка для продакшена:

```bash
npm run build
```
